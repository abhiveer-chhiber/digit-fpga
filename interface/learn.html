Handwritten digit recognition

Neural network training.

This neural network uses a custom dataset of 100 handwritten digits collected for this project. Eighty drawings were used for training and 20 for validation. The visualization uses actual model weights and recorded training checkpoints.

Pick a drawing. Follow it through the network. Then replay training to see how the weights and prediction change.

Interactive inference

Evaluate a new drawing.

Draw one digit from 0–9. The input follows the training pipeline: threshold-based cropping, proportional padding, BOX resizing, and pixel normalization.

Drawings are processed locally in the browser. Inference does not update model weights. The checkpoint slider selects recorded parameter states.

A target label enables correctness checks and cross-entropy gradients. The label is not used as a prediction input.
