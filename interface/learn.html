Why I started

I wanted to follow a prediction
all the way down to hardware.

I started this project in high school because I wanted to understand how a model learns, then work out how its calculations could run on an FPGA.

I drew my own digits, built the collector, and kept the original images. Then I compared resolutions, trained a simple baseline, and built a neural network in NumPy.

This page shows the software stage. FPGA inference is still ahead. The browser currently performs the model calculations using exported weights.

From drawing to prediction

The choices behind the code.

01 / DATA

Keep the original.

I captured drawings at 128×128 so I could make smaller versions from the same handwriting. Collecting separate drawings for each resolution would make the comparison harder to interpret.

original: 128 × 128
experiment A: 8 × 8 = 64 inputs
experiment B: 16 × 16 = 256 inputs

Writer IDs let me later separate people between training and testing. Right now, all 100 drawings are from one writer.

02 / PREPROCESSING

Center without stretching.

The script crops unused space and places the drawing in a padded square. It preserves proportions, so a narrow 1 does not become a wide rectangle. BOX resizing averages ink intensity instead of forcing pixels to black or white.

pixels = np.asarray(image, dtype=np.float32) / 255.0

Dividing by 255 changes the pixel range to 0–1. It does not change the handwriting or tell the model which digit it is.

03 / VALIDATION

Hold some drawings back.

I used 80 drawings for training and 20 for validation. Both resolutions use the same assignments. The validation labels are not used to update weights during training.

Validation helps me compare choices, but it is not an untouched final test set. With only 20 drawings, one mistake changes accuracy by five percentage points.

04 / FORWARD PASS

A neuron combines numbers.

Each neuron multiplies its inputs by weights, adds them together, and adds a bias. Hidden layers then use ReLU, which replaces negative values with zero.

values = activations[-1] @ weights + bias
values = np.maximum(values, 0)

Without a nonlinear activation between layers, stacking linear layers would still describe a linear transformation. ReLU lets the network represent more complex relationships.

05 / LEARNING

Work backward from the mistake.

Cross-entropy measures how much probability the model gives the correct label. Backpropagation uses the chain rule to find how each parameter affects that loss.

delta = probabilities - targets
weight_gradient = previous_activations.T @ delta

Training averages gradients across a batch and adds L2 regularization. Adam uses moving averages of gradients and squared gradients to choose parameter updates. It does not replace backpropagation.

I checked the gradients against numerical estimates before training. The largest absolute difference on the test network was about 1.33e-11.
