Integer inference

Fixed-point results.

The final neural network checkpoint was also evaluated using integer calculations. All four formats cover about −32 to 32 and use 32-bit accumulators. The comparison changes fractional precision.

Checkpoint 1000 · 80 training and 20 validation drawings
Storage / fractional bits Training correct Validation correct Validation agreement with float Maximum validation score error Saturation events

The 16-bit and 12-bit formats preserved the original predictions on all 100 drawings. The 10-bit format corrected one validation prediction. One changed prediction does not establish better performance on other handwriting.

With two fractional bits, the 8-bit format rounded 32,703 of 32,768 first-layer weights to zero. Accuracy dropped without saturation. This result applies to the tested scale, not every 8-bit model.

Agreement counts predictions matching the floating-point model. Score error compares output values after converting integers back to the original scale. Saturation events include both data splits.

The integer implementation matched a separate scalar reference in 150 generated test cases, including 66 with accumulator saturation.
