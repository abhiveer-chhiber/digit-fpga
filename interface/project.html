Project scope

From a learned model
to FPGA inference.

This project investigates how a handwritten digit classifier can move from a Python model into digital hardware. I use a custom dataset, compare model and number formats, and check hardware calculations against a software reference.

The software implementation includes a collection interface, image preprocessing, linear baselines, a NumPy neural network, fixed-point inference, and an interactive browser viewer.

A single neuron is also implemented in SystemVerilog. Its outputs and saturation flags matched the Python reference in all 416 simulation cases. The testbench also checks reset, input gaps, saved bias and ReLU settings, and control-signal behavior.

The complete neural network has not yet been implemented in RTL, synthesized, or run on a physical FPGA. The public Explorer performs predictions in the browser, using the exported software model. FPGA timing and resource use have not been measured.
