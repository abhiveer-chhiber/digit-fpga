Project scope

Software reference
for FPGA inference.

This project investigates the relationship between learned models, numerical precision, and FPGA inference.

The implementation includes a custom handwritten dataset, a collection interface, a preprocessing pipeline, and a linear baseline and multilayer neural network implemented in NumPy.

The current implementation covers software training, verified checkpoint export, and browser inference. FPGA execution has not yet been implemented.
